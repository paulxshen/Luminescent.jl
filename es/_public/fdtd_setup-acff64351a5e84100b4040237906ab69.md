## Opción 1: Python local + Lumi Colab remoto 
Ejecute Python localmente. `lumi.solve` sube los archivos del problema al servidor de Lumi Colab y descarga los archivos de la solución. 
### Requisitos previos
- Python (se recomienda la distribución Anaconda para usuarios de Windows)
- VS Code, Cursor u otro IDE
- En una VM Linux puede necesitar
```
sudo apt-get update
sudo apt install -y harminv  libxi6 libxxf86vm1 libxrender1 libgl1 libglx-mesa0 libsm6 libice6 libxext6 libglib2.0-0 libglu1-mesa libxcursor1 libxft2 libxinerama1
```
### Pasos
- `pip install -U luminescent`
- Configure la variable de entorno LUMI_TOKEN con su [token de Lumi Colab](https://colab.luminescentai.com/colab/hub/token) y luego reinicie su terminal o IDE.
