El modo incógnito implica cero retención de datos: con la configuración local de Python, el servidor elimina la ejecución en cuanto el cliente la ha recibido.

Actualice a Pro o Max: info@luminescentai.com

Opción 1: Python local + Lumi Colab remoto¶

Ejecute Python localmente. lumi.solve sube los archivos del problema al servidor de Lumi Colab y descarga los archivos de la solución.

  • pip install -U luminescent

  • Obtenga su token de Lumi Colab y guárdelo una sola vez: python -c "import luminescent as lumi; lumi.set_token('<token>')"

Opción 2: completamente local¶

Python local y ejecutable FDTD local. Disponible para clientes de pago que superen cierto umbral de gasto.
